# 两轮电动车 BLE 解锁 — v0.2

## 产品行为
1. 手机(配对并 BIND)靠近到 RSSI > -70 → 进入 **ARMED**(准备)，不立刻通电
2. 准备态下捏刹车 / 轻推车(SW-420 检测到震动) → **2 秒内**吸合继电器通电
3. 人离开约 30 秒 → 自动断电
4. 完全锁车且未在准备态时，短时多次震动 → 蜂鸣器防盗报警
5. iPhone 无感：固件在绑定后订阅 **ANCS**，由 iOS 系统保活蓝牙连接(锁屏/杀 App 不断)

## 接线 (ESP32-C3)
- 5V 降压 → C3 5V / 继电器 VCC / 蜂鸣器 VCC；GND 共地
- GPIO3 → 继电器 IN（默认高电平触发；低电平触发把 `RELAY_ACTIVE` 改成 `LOW`）
- GPIO4 → 有源蜂鸣器
- GPIO5 → SW-420 DO（传感器用 3.3V）

## 编译
Arduino IDE，板子 ESP32C3 Dev Module，USB CDC On Boot 开；库：NimBLE-Arduino 2.x

## 首次配对
1. nRF Connect 连 `EBike-Lock`，允许系统配对
2. 写 `PWD:123456:你的新密码`
3. 写 `BIND:新密码`；iPhone 可能弹「允许通知」→ 允许（这就是 ANCS）
4. 锁屏走远再走回：应自动重连；靠近后短鸣一声(ARMED)，捏刹车应通电

## 验收建议
- 走到车旁捏刹车，2 秒内通电
- 锁屏 10 分钟后仍能自动重连并开锁（成功率目标 ≥95%）
- 隔一堵墙不应进入 ARMED（可把 RSSI_NEAR 再调严，如 -65）

## 已定型号 (助理选型)
- 继电器: 5V 光耦单路, **跳线选高电平触发**, `RELAY_ACTIVE=HIGH`
- 蜂鸣器: KY-012 有源, GPIO 高电平响
- 震动: SW-420
- 降压: 9–120V→5V
- 固件 v0.2.1: 上电先写低再设 OUTPUT, 避免重启误吸合
