# 接线与装配说明 v0.1

## 电源
- 电池正极接 2A 保险丝，保险丝出来接降压模块 VIN+；电池负极接降压 VIN− 和公共地
- SMBJ64A 接在保险丝后面：阴极接正极，阳极接地
- 降压模块的 5V 输出接 C3 的 5V 脚和继电器 VCC；C3 的 3.3V 接 SW-420 和 KY-012 的 VCC；所有模块共地

## 信号
| 模块 | 引脚 | C3 GPIO |
|---|---|---|
| 继电器 | IN，高电平触发 | GPIO3 |
| KY-012 | S，高电平响 | GPIO4 |
| SW-420 | DO | GPIO5 |

继电器的 COM 和 NO 用 PCT-222 并到电门锁两根线上，不剪原车线。

## 外壳（cad/enclosure.scad，body.stl 和 lid.stl）
- 内腔 80×50×25mm，壁厚 2mm，建议用 PETG 打印
- C3 放在 +X 端卡槽里，天线朝外壁，周围 1cm 内不放金属和线束
- -X 端开 PG7 格兰头孔，走电源 2 根加电门锁 2 根
- SW-420 用 M3 螺丝固定在铜柱上；降压模块和继电器用热熔胶贴在盒底
- 蜂鸣器贴着 +Y 侧壁的 2mm 出声孔
- 两侧有扎带耳，用扎带固定在车架上，不要贴着电池金属壳
- 盖子用 4 颗 M3 自攻螺丝，接缝处打一圈硅胶防水

## 装配和测量顺序
1. 只接降压模块，量输出是否在 5V 左右
2. 依次接上 C3、继电器、传感器和蜂鸣器，最后接电门锁线
3. 拆掉 C3 和继电器板上的电源指示灯
4. 在电池那一侧分三段量锁车待机电流：只接降压模块、再加 C3、再加继电器板。第一版不超过 5mA，下一版目标 2mA
